เมนู “โรคปลา” รวมโรคจากปลาทุกชนิด ค้นหาจากอาการที่สังเกตเห็นได้ และมีลิงก์กลับไปยังหน้ารายละเอียดปลาที่เกี่ยวข้อง
เมนู “เปรียบเทียบปลา” เลือกปลา 2–4 ชนิดเพื่อเทียบข้อมูลการเลี้ยง และแชร์ผลได้จากลิงก์ในหน้าตาราง

วิธีรัน (ครั้งแรก)

python -m venv venv
venv\Scripts\activate          (Windows)  |  source venv/bin/activate  (Mac/Linux)
pip install -r requirements.txt
python app.py

เปิด http://127.0.0.1:5000 — terminal ควรขึ้น "โหลดปลาได้ N ตัว"

ครั้งถัดไป: แค่ `venv\Scripts\activate` แล้ว `python app.py`

เผยแพร่เว็บผ่าน GitHub และ Render

1. สร้าง repository ใน GitHub แล้วอัปโหลดโค้ดชุดนี้ โดยไม่อัปโหลดโฟลเดอร์ `.venv/`, `venv/` หรือไฟล์ `.env`
2. ที่ Render เลือก **New → Blueprint** แล้วเชื่อมต่อ repository นี้
3. Render จะอ่าน `render.yaml` เพื่อติดตั้งแพ็กเกจและเริ่มเว็บด้วย Gunicorn ให้โดยอัตโนมัติ
4. เมื่อ deploy สำเร็จ Render จะแสดง URL สาธารณะของเว็บไซต์ และ deploy ใหม่เมื่อมีการ push การเปลี่ยนแปลงขึ้น GitHub

ไฟล์ `render.yaml` ใช้แผน Free ของ Render หากตัวเลือกแผนหรือเงื่อนไขของ Render เปลี่ยน ให้ตรวจสอบรายละเอียดในหน้า Render ก่อนยืนยัน

โครงสร้าง

| โฟลเดอร์/ไฟล์ | คืออะไร | ใครดูแล |
|---|---|---|
| app.py | โปรแกรมหลัก อ่านทุก .json ใน data/ แล้วแสดงผล | ทีมเว็บ |
| data/ | ข้อมูลปลา 1 ชนิด = 1 ไฟล์ (ดูคู่มือใน docs/) | ทีมข้อมูล |
| unused/ | ข้อมูลที่ตัดออก ไม่ขึ้นเว็บ (เช่น กะพงขาว) | — |
| static/img/ | รูปปลา ชื่อไฟล์ตรงกับช่อง image ใน JSON | ทีมรูป |
| templates/ | หน้าเว็บ HTML | ทีมเว็บ |
| PLAN.md | แผนงาน บทบาท สถานะ | หัวหน้าโปรเจกต์ |
| PROMPT_LOG.md | บันทึกการใช้ AI ตามขั้นตอนรายวิชา | หัวหน้าโปรเจกต์ |

กติกาสั้น ๆ

1. ก่อนทำงาน `git pull` / เสร็จแล้ว commit + push ทันที
2. เพิ่มปลา = วางไฟล์ใน data/ แล้วรันใหม่ ไม่ต้องแก้โค้ด
3. ห้ามแก้ชื่อช่องใน JSON — ถ้าต้องเพิ่ม คุยกับหัวหน้าโปรเจกต์ก่อน
4. ข้อมูล `food` ใช้ช่อง `time`, `quantity` และ `method` สำหรับเวลา ปริมาณ และวิธีให้อาหาร หากแหล่งข้อมูลไม่ได้ระบุ ให้ใส่ “ยังไม่มีข้อมูลระบุ”
5. ถ้า terminal ขึ้น "[ข้าม] xxx.json" = ไฟล์นั้น JSON พัง ส่งให้เจ้าของไฟล์แก้
